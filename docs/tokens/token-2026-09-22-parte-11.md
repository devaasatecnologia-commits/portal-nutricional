### 🧪 LIÇÕES APRENDIDAS (atualizado na sessão 2026-09-22 parte 11)

**25. Tabela `usuario` tem PK `idusuario` (não `id`) e coluna `username` (não `nome`)**
Sempre que fizer JOIN com `usuario`, usar `u.idusuario` e `COALESCE(u.username, 'Sistema')`. Errar isso gera `SQLSTATE[42703]: Undefined column`.

**26. Tabelas que usam `data_hora` em vez de `created_at`**
`frota_log_embarque` e `frota_historico_posicao` usam `data_hora`. Sempre usar `data_hora AS created_at` no SELECT se o frontend espera `created_at`.

**27. `frota_entrega_timeline` usa `created_at`**
Ao contrário das outras, essa usa `created_at`. Sempre conferir antes com `information_schema.columns`.

**28. Console do navegador > PowerShell para testar endpoints com token**
O PowerShell 5.1 tem dificuldades com `Get-Clipboard` quando o terminal integrado do VSCode intercepta. Usar o Console do DevTools (`copy(localStorage.getItem('authToken'))` ou `fetch` direto) é mais confiável.

**29. Sempre conferir `colspan` das tabelas ao mudar colunas**
Quando se adiciona/remove colunas em uma tabela, o `colspan` das linhas de "tabela vazia" e "carregando" precisa ser atualizado, senão o layout quebra.

**30. Score pode ser reutilizado entre dimensões quando a estrutura de dados é idêntica**
`calcularScoreMotorista()` foi reusado para veículos porque a fórmula depende apenas dos mesmos campos (entregas, pontualidade, divergência, problemas, eficiência de trajeto).

### 🧪 LIÇÕES APRENDIDAS (atualizado na sessão 2026-09-22 parte 11)

**25. Tabela `usuario` tem PK `idusuario` (não `id`) e coluna `username` (não `nome`)**
Sempre que fizer JOIN com `usuario`, usar `u.idusuario` e `COALESCE(u.username, 'Sistema')`. Errar isso gera `SQLSTATE[42703]: Undefined column`.

**26. Tabelas que usam `data_hora` em vez de `created_at`**
`frota_log_embarque` e `frota_historico_posicao` usam `data_hora`. Sempre usar `data_hora AS created_at` no SELECT se o frontend espera `created_at`.

**27. `frota_entrega_timeline` usa `created_at`**
Ao contrário das outras, essa usa `created_at`. Sempre conferir antes com `information_schema.columns`.

**28. Console do navegador > PowerShell para testar endpoints com token**
O PowerShell 5.1 tem dificuldades com `Get-Clipboard` quando o terminal integrado do VSCode intercepta. Usar o Console do DevTools (`copy(localStorage.getItem('authToken'))` ou `fetch` direto) é mais confiável.

**29. Sempre conferir `colspan` das tabelas ao mudar colunas**
Quando se adiciona/remove colunas em uma tabela, o `colspan` das linhas de "tabela vazia" e "carregando" precisa ser atualizado, senão o layout quebra.

**30. Score pode ser reutilizado entre dimensões quando a estrutura de dados é idêntica**
`calcularScoreMotorista()` foi reusado para veículos porque a fórmula depende apenas dos mesmos campos (entregas, pontualidade, divergência, problemas, eficiência de trajeto).

**31. CSS do 5.C.2 ficou pendente no commit do JS**
Os estilos `.cargas-eficiencia-toolbar`, `.cargas-eficiencia-filtros`, `.eficiencia-legenda-cobli` e `.cobli-score-placeholder` foram adicionados após o `git add` do JS e ficaram fora do commit `808b2e7`. Corrigido neste token (commit seguinte).
