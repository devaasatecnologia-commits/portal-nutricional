🧪 LIÇÕES APRENDIDAS (sessão 2026-09-24 parte 17)
44. JwtMiddleware mascara erros como 401

O try/catch (\Exception $e) englobando o $handler->handle($request) faz qualquer PDOException do Controller virar 401 Token inválido. Correção ideal: mover $handler->handle() para fora do try/catch.

Sintoma: um token válido retorna 200 em uma rota e 401 em outra. Log de debug no middleware revelou a PDOException.

45. item.unidade não existe — usar unidade.descricao via JOIN

O ERP tem item.idunidadebasica (FK) apontando para unidade.idunidade. Não tem item.unidade. SQL correto:

sql
COALESCE((SELECT descricao FROM unidade WHERE idunidade = i.idunidadebasica), 'UN') AS unidade
46. Checklist salvo pelo motorista é ponto de verdade

O backend deve derivar $temFaltante, $temDevolucao, $temAberto do checklist enviado, não confiar em flags do frontend. Log de divergência se as flags não baterem.

47. Cálculo de diferença em JS precisa de Math.round

12 - 11.999999999999998 = 2e-15, que toFixed(2) mostra como 0.01. Sempre usar Math.round(previsto) - Math.round(entregue) e enviar inteiros no payload.

48. statusLabel e ehDivergencia (dead code) confundem manutenção

Não declarar variáveis que não são usadas. ESLint reclama e futuras sessões gastam tempo investigando.

49. CHECK constraint de tipo_problema precisa incluir todos os estados do domínio

Ao introduzir 'aberto' como estado válido, atualizar o CHECK antes de testar. Ordem correta:

Identificar nome do constraint:

sql
SELECT conname FROM pg_constraint
WHERE conrelid = 'frota_entrega_problema'::regclass
  AND contype = 'c'
  AND pg_get_constraintdef(oid) LIKE '%tipo_problema%';
DROP CONSTRAINT ...

ADD CONSTRAINT ... com a lista atualizada

Só então testar o fluxo no app

50. Get-Clipboard do PowerShell pode devolver lixo

Ao copiar JWT do DevTools, a opção "Copy string contents" (não "as JavaScript literal", não "as JSON literal") é a única correta. Sempre validar:

powershell
$token = (Get-Clipboard).Trim()
Write-Host "Tamanho: $($token.Length) chars, Segmentos: $($token.Split('.').Count)"
JWT = 200-600 chars, 3 segmentos. Se vier < 100, é lixo — copiar de novo.

51. frota_entrega_problema_tipo_problema_check — lista canônica

text
faltante, devolucao, avaria, extraviado, outro, aberto
52. statusRotaMotorista() e atualizarPainelRota() — nomes propositalmente diferentes

statusRotaMotorista retorna [label, cssClass] para o painel admin. atualizarPainelRota atualiza a barra de progresso da rota. Não confundir.

53. frota_checklist_entrega.status — mesma lista de frota_entrega_problema?

NÃO. Enquanto frota_entrega_problema.tipo_problema tem um domínio amplo (faltante, devolucao, avaria, extraviado, outro, aberto), o frota_checklist_entrega.status tem um domínio menor (entregue, faltante, devolvido, aberto). Manter essa separação.
