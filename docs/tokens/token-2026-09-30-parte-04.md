🧪 LIÇÕES APRENDIDAS (71-98)

========================================



71\. entity\_id no cache ≠ motorista\_id da frota

&#x20;   Cache Cobli usa UUID do próprio Cobli. JOIN obrigatório

&#x20;   via frota\_cobli\_motorista. Sem isso, vazio silencioso.



72\. SUM de snapshots com períodos sobrepostos infla o total

&#x20;   Cache reinsere mesmo período. Usar ORDER BY atualizado\_em

&#x20;   DESC LIMIT 1 para pegar o snapshot mais recente.



73\. Fallback PHP para campos opcionais de API externa

&#x20;   Cobli não expõe velocidade\_media no ranking. Calcular

&#x20;   (km / (tempo/60)) no PHP resolve.



74\. Ranking anônimo: RANK() OVER + COUNT(\*) OVER () na mesma query

&#x20;   Garante consistência atômica entre posição e total.



75\. Cache PHP com TTL curto exige limpeza antes de validar

&#x20;   Get-ChildItem $env:TEMP -Filter "cobli\_score\_motorista\_\*.json"

&#x20;   | Remove-Item -Force



76\. rank do cache nem sempre é RANK() do SQL

&#x20;   Escolhemos o do SQL (Opção B) para consistência.



77\. node --check silencioso ≠ código correto

&#x20;   Só valida sintaxe. Não valida exposição em window nem

&#x20;   se os IDs existem no HTML.



78\. Integração externa precisa ser EXECUTADA, não só codificada

&#x20;   vincularMotoristasAuto() existia mas nunca rodou.

&#x20;   SEMPRE rodar a sincronização após implementar.



79\. console.table + check object é o padrão de validação

&#x20;   21-35 assertions em 1 bloco, feedback visual imediato.

&#x20;   Reutilizar em todo pacote.



80\. Ordem de declaração de let vs. boot no IIFE

&#x20;   let tem temporal dead zone. Todo estado lido pelo boot

&#x20;   deve estar no TOPO do IIFE.



81\. PDO + PostgreSQL NUMERIC vira string no JSON

&#x20;   (float)$valor na borda da API normaliza.



82\. Normalizar na borda da API ≠ normalizar no frontend

&#x20;   Fazer as duas: JS tem paraNumero() como defesa; backend

&#x20;   faz (float) na origem.



83\. (float)'' retorna 0.0 (não null)

&#x20;   Checar === null || === '' ? null : (float)$valor.

&#x20;   Senão coordenada vazia vira (0,0).



84\. array\_key\_exists vs isset quando o valor pode ser null

&#x20;   isset retorna false para null. array\_key\_exists é o correto.



85\. Chip distância calculando 204 km NÃO é bug se o motorista

&#x20;   está longe. Contexto importa.



86\. Um bug de tipo pode quebrar N lugares silenciosamente

&#x20;   typeof latitude === 'number' quebrado afetava mapa + chip

&#x20;   + next-stop-distance.



87\. Regex de validação precisa de âncora

&#x20;   /\~\[\\d]+(min|h)/ sem ^ e $ casa em texto corrompido.

&#x20;   Ancorar: /^\~\\d+\\s?(min|h)/



88\. Teste com dados reais ≠ teste com dados mockados

&#x20;   Modo treino (motorista em Criciúma) vs produção (motorista

&#x20;   em campo). Sempre considerar contexto.



89\. Bump do SW é obrigatório em toda mudança de JS/CSS/HTML

&#x20;   ignoreSearch: true invalida o ?v= do PHP.

&#x20;   Sempre bump CACHE\_NAME.



90\. Deploy FTP — nunca subir .env

&#x20;   Sempre backup remoto antes de sobrescrever.



91\. Testar UX no navegador antes de codar feature nova

&#x20;   35 checks validados em 1 script.



92\. Painel só carrega ao clicar na aba

&#x20;   carregarPainelMotorista() é lazy. Rodar check antes de

&#x20;   clicar retorna valores vazios.



93\. Service Worker não controla a 1ª carga após limpar

&#x20;   Depois de unregister, o SW assume na 2ª navegação.



94\. fitBounds com pontos muito distantes amontoa marcadores

&#x20;   Em modo treino, marcadores ficam juntos. Melhoria

&#x20;   conhecida (Mapa-fitBounds, Opção B).



95\. O mapa do gestor (gestao-cargas.php) e do motorista

&#x20;   propósitos diferentes. Ajustar fitBounds só no motorista.
