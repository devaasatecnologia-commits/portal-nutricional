### 🎯 BLOCO 7.A.1 — CACHE 30s EM posicoesFrota() ✅

**Objetivo:** evitar 18 chamadas HTTP em série à Cobli quando a posição já está fresca no banco.

**Regra:**
- Antes de chamar Cobli: consulta `frota_cobli_posicao` pelo `veiculo_id` com `created_at >= NOW() - INTERVAL '30 seconds'`
- Cache hit → usa do banco (não chama Cobli)
- Cache miss → chama Cobli, grava, retorna

**Decisão arquitetural crítica:**
- **Usa `created_at` (hora da gravação local), NÃO `capturado_em` (hora da Cobli)**
- Motivo: a Cobli pode devolver posições antigas (vimos caso de 5 dias), então `capturado_em` nunca estaria fresco. `created_at` reflete quando a linha foi gravada por nós.

**Entregas:**

**Backend:**
- `CobliController::posicoesFrota()` — refatorado para consultar cache antes
- `CobliController::posicaoVeiculo()` — refatorado com mesma lógica
- `CobliController::buscarUltimaPosicaoCache($veiculoId, $segundosJanela)` — método novo privado
- Retorna no `meta`: `total`, `cache_hits`, `cache_miss` para diagnóstico

**Validação (com números reais):**

| Teste | Tempo | Cache hits | Cache miss |
|---|---|---|---|
| 1ª chamada (cache frio) | 15.877 ms | 0 | 18 |
| 2ª chamada em < 30s | **447 ms** | **18** | **0** |
| 3ª chamada em > 30s | 16.176 ms | 0 | 18 |

**Ganho comprovado:** 97% de redução quando o cache está quente (15.8s → 447ms).

**Comportamento validado:**
- Após cache hit, NÃO grava linhas novas no banco (18 linhas do teste A, não 36)
- Após expiração de 30s, chama Cobli novamente (correto)
- `meta.cache_hits` e `meta.cache_miss` refletem a realidade

🔴 BLOCO 7.A.2 — curl_multi (PRÓXIMO)
Objetivo: reduzir primeira chamada (cache frio) de 15-18s para ~2-3s.

Problema atual:

php
foreach (18 veículos) {
    $resposta = chamaCobli();  // espera 1-2s cada
}
// total: 18-36s
Solução:

php
$multi = curl_multi_init();
foreach (18 veículos) {
    $ch = curl_init();
    curl_multi_add_handle($multi, $ch);  // dispara em paralelo
}
while (curl_multi_exec($multi, $running)) { ... }
// total: ~2-3s (o tempo da mais lenta)
Ganho esperado:

Cenário	Hoje	Depois
1ª chamada (cache frio)	15-18s	~2-3s
