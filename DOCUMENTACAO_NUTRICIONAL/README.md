## 🚀 INSTALAÇÃO LOCAL
1. Acessar projeto
cd C:\xampp\htdocs\API

2. Instalar dependências
composer install

3. Configurar .env
4. Iniciar servidor
php -S localhost:8080 router.php

5. Acessar
http://localhost:8080/portal/
